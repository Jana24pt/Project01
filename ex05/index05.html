Basic Linux Commands

I am learning Linux because I want to understand how computers and servers work. Practice is important, so I use the terminal every day.

Commands I Use

  • pwd - Show the current directory.
  • ls - List files and folders.
  • cd - Change the directory.
  • mkdir - Create a new folder.

I try each command and write down what I learn.
Small steps make a difference.

My Study Plan

  1. Open the terminal.
  2. Practice commands.
    • Create files and folders.
    • Move between directories.
  3. Review my notes.
